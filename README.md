# Новая тестовая гостиная «Навигатор в Матрице 8D»

**Статус: локальная GitHub Pages-структура, не опубликовано.**

Это чистая подготовка будущего отдельного тестового сайта. Она создана из принятого экранного макета и не является изменением старого репозитория `navigator-test`.

## Состав

- `index.html` — открытая гостиная;
- `my-space.html` — Путеводитель;
- `my-circle.html`, `my-events.html`, `relationships.html`, `team-work.html`, `my-library.html` — подготовленные комнаты макета;
- `Ресурсы макета/` — изображения Домового, Бабы Яги, Кащея и заставочное видео.

## Границы подготовки

- Не опубликовано в GitHub Pages и не привязано к репозиторию.
- Не подключено к Supabase и не содержит ключей или Magic Link.
- Не создаёт пользователей, профили, события или другие данные.
- Не затрагивает основной Навигатор в Матрице 8D, старый `navigator-test` и локальные рабочие данные.

Для локальной проверки открывается `index.html`.
